# 🛡️ SpecGuard (스펙가드)

## 1. 서비스 소개

SpecGuard는 외주 개발 회사의 프로젝트 매니저(PM)와 기획 담당자가 고객 요구사항의 최종 기획서 반영 여부를 확인하도록 돕는 AI 기반 웹 서비스입니다.

회의록과 메모에서 요구사항을 추출하고, 사용자가 검토·확정한 요구사항을 최종 기획서와 비교해 누락된 항목을 확인합니다.

## 2. 개발 목적

- 고객과 협의한 요구사항의 누락 방지
- 반복적인 문서 비교 및 검토 업무 부담 감소
- 고객과 개발자 간 의사소통 오류 감소
- 체계적인 요구사항 관리 지원

## 3. 주요 기능

### 정상 동작을 확인한 기능

- **회의록 업로드:** 회의 내용을 담은 TXT, MD, PDF, DOCX 파일을 등록할 수 있습니다.
- **메모 직접 입력:** 회의별 날짜와 함께 협의 내용을 입력할 수 있습니다.
- **요구사항 수정:** 추출된 요구사항 문장을 검토·수정할 수 있습니다.

### 추가 검증이 필요한 기능

- **AI 요구사항 추출:** 회의록과 메모에서 고객 요구사항을 추출합니다.
- **원문 근거 표시:** 추출한 요구사항과 함께 근거가 된 문장과 회의 날짜를 보여줍니다.
- **요구사항 삭제 및 확정:** 불필요한 항목을 삭제하고 비교할 요구사항을 확정합니다.
- **기획서 비교:** 확정된 요구사항과 최종 기획서를 LLM으로 비교합니다.
- **누락·충돌 확인:** 기획서에 반영되지 않았거나 상반되는 내용이 있는지 확인합니다. LLM 결과는 참고용이며 원문 확인이 필요합니다.

## 4. 서비스 사용 방법

전체 이용 흐름은 다음과 같습니다. AI 분석 및 비교 결과는 원문과 대조해 확인해 주세요.

1. **프로젝트 생성** — 프로젝트 이름과 고객사 정보를 입력합니다.
2. **자료 등록** — 회의록 파일을 업로드하거나 날짜별 회의 내용을 메모로 입력합니다. 최종 기획서도 입력하거나 파일로 등록합니다.
3. **AI 요구사항 분석** — 요구사항 추출 화면에서 “AI 분석”을 실행합니다.
4. **요구사항 검토 및 수정** — 추출된 문장, 카테고리, 회의 날짜와 원문 근거를 확인하고 내용을 수정합니다.
5. **비교 기준 확정** — 기획서와 비교할 요구사항을 확정합니다. 확인 필요와 삭제된 항목은 비교에서 제외됩니다.
6. **기획서 비교** — “기획서 비교”를 실행해 확정 요구사항과 최종 기획서를 비교합니다.
7. **결과 확인** — 반영됨, 누락 의심, 충돌 상태와 회의록·기획서 근거를 확인합니다.

## 5. 기술 스택

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js 내장 HTTP 서버
- **AI Model:** `jitda-chat`
- **데이터 형식:** JSON, 브라우저 `localStorage`
- **LLM 응답 형식:** JSON Schema
- **문서 텍스트 추출:** TXT·MD, PDF.js(PDF), Mammoth(DOCX)
- **개발 플랫폼:** JITDA(짓다)
- **버전 관리:** Git, GitHub

## 7. 설치 및 실행 방법

### 저장소 복제

```sh
git clone https://github.com/worryjeong/jitda-project.git
cd jitda-project
```

### 환경 변수 설정

LLM 기능을 사용하려면 다음 환경 변수를 설정합니다. 실제 API 키 값은 저장소나 README에 포함하지 마세요.

- `LLM_API_KEY`: LLM API 인증 키
- `LLM_BASE_URL`: LLM API 기본 주소
- `PORT`: 서버 포트 (선택 사항, 기본값 `3000`)

### 서버 실행

프로젝트 루트에서 실행합니다.

```sh
npm start
```

`npm start`는 `node server.js`를 실행합니다. 환경 변수는 실행 환경에 미리 설정되어 있어야 합니다.

### 서비스 접속

웹 브라우저에서 다음 주소로 접속합니다.

http://localhost:3000

AI가 추출한 요구사항과 비교 결과는 실제 고객의 요청과 다를 수 있습니다. 반드시 회의록·메모 원문과 기획서를 대조해 결과를 검토해 주세요. 프로젝트 데이터는 현재 사용 중인 브라우저의 `localStorage`에 저장되므로 다른 브라우저나 기기와 자동 공유되지 않습니다.
