요구사항 검토 가이드

              
AI가 정리한 문장을 회의 원문과 비교해 보세요. 근거를 확인하고, 상태를 선택하고, 필요한 수정 사항을 메모하면 됩니다.

            


            

              
                
              
              

                검토의 기준은 AI가 아니라 원문과 실제 합의입니다.
                
AI 결과는 확인을 돕는 초안이에요. 확실하지 않다면 서둘러 확정하지 말고 원문을 더 살펴보세요.

                01 원문 근거 확인
                02 상태 선택하기
                03 수정 의견 남기기
                04 검토 마무리
              


              

                

                  

                    01
                    

                      
먼저 원문 근거를 확인하세요

                      
요구사항 문장만 읽지 말고, 어디에서 나온 내용인지 함께 살펴봅니다.

                    

                  

                  
    
                    
  • 인용된 회의 내용이 원문에도 실제로 있는지 확인합니다.
    • 
                    
  • 회의 날짜와 회차를 보고, 나중에 변경되거나 취소된 요청은 아닌지 살펴봅니다.
    • 
                    
  • “근거 확인 불가”가 표시되면 원문에서 직접 확인하기 전까지 확정하지 않습니다.
    • 
                  

                  
이전 회의 내용도 비교하고 싶다면 “전체 보기”를 눌러 모든 회차를 확인하세요. 최근 회차만 보는 화면에서는 최신 내용에 집중할 수 있습니다.

                


                

                  

                    02

                      검토 필요
                      
아직 판단하기 어려워요

                      
요청이 모호하거나 근거·변경 내용을 더 확인해야 할 때 그대로 두세요.

                    

                    

                      확정
                      
비교 기준에 포함해요

                      
원문과 고객 합의에서 확인했고, 최종 기획서에 반영되어야 하는 항목만 확정하세요.

                    

                    

                      삭제
                      
기준에서 제외해요

                      
중복·오인식이거나 최종 요청이 아닌 항목을 제외합니다. 필요하면 “삭제된 항목 보기”로 다시 확인할 수 있어요.

                    

                  

                  
기획서 비교는 “확정”된 요구사항만 사용합니다. 상태를 확신하기 어렵다면 확정 대신 검토 필요로 남겨두세요.

                


                

                  

                    03
                    

                      
요구사항이 달라졌다면 수정 메모를 남기세요

                      
원래 추출 문장을 덮어쓰기보다, 어떻게 바뀌어야 하는지 기록합니다.

                    

                  

                  

                    
먼저“메모로 수정” 선택

                    
다음변경 내용과 이유를 적고 저장

                    
마지막추출 화면에서 “요구사항 다시 확인”

                  

                  
예: “비회원도 이용” 요청이 “로그인한 회원만 이용”으로 바뀌었다면, 새 조건과 변경된 회차를 메모에 적어주세요. 다시 확인하면 기존 내용과 수정 의견을 함께 분석합니다.
